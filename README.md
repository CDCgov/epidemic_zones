# Defining influenza epidemic zones through temporal clustering of global surveillance data

This repository contains all code used to conduct the analysis for the 
journal article "Defining influenza epidemic zones through temporal clustering of global surveillance data".

Preprint available at [https://www.medrxiv.org/content/10.64898/2026.04.17.26351048v1](https://www.medrxiv.org/content/10.64898/2026.04.17.26351048v1).

## Repository Contents and Software Notes

**Base Project Script:**

The Rmarkdown file [`Epidemic_Zones.rmd`](Epidemic_Zones.rmd) contains the complete, current analysis
for this project (WHO FluNet-derived influenza testing data, per-country GAM burden curves,
country-level clustering into epidemic zones, and comparison to WHO transmission zones). The rendered
document can be viewed in the corresponding output file [`Epidemic_Zones.html`](Epidemic_Zones.html).
**This is the most current and only actively maintained analysis document.**

The document is organized into the following sections:

1. Reading and Cleaning Influenza Testing Data
2. Country Categorization
3. Generation of Windowed Generalized Additive Model (`mgcv::gam`)
4. Burden calculations
5. Clustering (data splitting, clustering/weighting functions, ensemble generation and evaluation,
   final consensus clustering, and cluster-level summary GAM curves)
6. Hypothetical Proxying of Countries With Limited Data
7. Epidemic Zones Compared to Transmission Zones
8. Code in preparation for Supplementary Tables and descriptive statistics in the Results

**Files/Directories:**

- [`renv.lock`](renv.lock) / [`renv/`](renv/): `renv` R package lock file and library management folder for the project.
- [`references.bib`](references.bib): Bibliography used for in-text citations in `Epidemic_Zones.rmd`.
- [`Dockerfile`](Dockerfile): Multi-platform container image definition (based on `rocker/rstudio:4.5.2`) used to build the docker image for running the analysis and ancillary scripts (e.g. the leave-one-out analysis).
- [`data/`](data/): Input data used in the analysis (FluNet exports, country/region lookups, intermediate clustering and GAM outputs, etc.) -- see [Data Files](#data-files) below for the source of each file.
- [`plots/`](plots/): Plots generated by the analysis.
- [`imgs/`](imgs/): Images used as examples in the analysis from external sources.
- [`scripts/`](scripts/): Standalone R scripts run outside the main Rmarkdown document, primarily the leave-one-out (LOO) analysis of latitudinal proxying (`loo_analysis.R`, `loo_analysis_alignment.R`) and their Singularity/HPC launcher scripts (`run_loo_singularity.sh`, `run_loo_alignment_singularity.sh`).
- `Epidemic_Zones_files/`: `knitr` generated figure/asset output from rendering `Epidemic_Zones.rmd`.

### Running the Docker Container (RStudio Server)

The image (built from the `Dockerfile` in this repository) bundles R 4.5.2 and
all `renv`-pinned packages, and launches RStudio Server on container start.

**1. Pull the image:**

```bash
docker pull cdcgov/influenza-clustering:v1.3
```

**2. Start the container from the root of this repository**, binding the repo
into the container's `/project` working directory (the same path the
`Dockerfile` uses) so every file here is read/write accessible from RStudio:

```bash
cd epidemic_zones   # repo root

docker run -d \
  --name influenza-clustering \
  -p 8787:8787 \
  -e PASSWORD=<choose-a-password> \
  -e USERID=$(id -u) \
  -e GROUPID=$(id -g) \
  -v "$(pwd):/project" \
  ncy6/influenza-clustering:v1.3
```

`USERID`/`GROUPID` make the container's `rstudio` user match your host user,
so files created or edited through RStudio keep correct ownership/permissions
on the bind-mounted repo.

**3. Open RStudio Server** at <http://localhost:8787> and log in with
username `rstudio` and the password you set above. The project directory
(`/project`, containing this repository) opens as the default working
directory with full read/write access.

To stop and remove the container later: `docker stop influenza-clustering && docker rm influenza-clustering`.
